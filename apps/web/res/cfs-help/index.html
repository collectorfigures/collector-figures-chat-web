Collector Figures

Private community chat

The Collector Figures Web/PWA is the official supported client. It works in a desktop or mobile browser and can be installed to your home screen.

Install the PWA

  • Chrome or Edge: use Install app in the browser menu.
  • Android 13+ Chrome: open the browser menu and choose Install app.
  • iOS 18 Safari: use Share → Add to Home Screen, then launch the installed app.
On iPhone and iPad, background Web Push requires the Home Screen PWA. A normal Safari tab does not provide the same closed-app notification capability.

Notifications

Open Settings → Notifications and enable Collector Figures Web Push. The system notification is intentionally generic: it does not contain message text, email, or your public Matrix ID. Logging out removes this browser's Matrix pusher and Push subscription.

Device verification

Verify a new browser or device with another trusted session whenever possible. A failed verification attempt does not damage your account; return and use another trusted session or your Recovery Key.

Recovery Key

Save your Recovery Key in your password manager. Collector Figures support cannot recreate it or decrypt your messages. If you reset cryptographic identity, previously encrypted history may become unavailable on the reset device.

Optional Element X client

Official Element X may be used as an optional third-party Matrix client. Its name, icon, release process, and Push infrastructure are operated by Element and are not controlled by Collector Figures. The official supported Collector Figures experience is this Web/PWA.

Privacy and diagnostics

No product analytics are enabled. Diagnostic logs are not uploaded automatically. Only submit a diagnostic file when you actively choose to do so, after reviewing it for personal information.
